## 재생 규칙

- 각 도장이 화면(아래쪽 22% 제외)에 60% 이상 들어오면 재생 — 장마다 따로.
- 한 번 찍히면 유지. 위로 올렸다 다시 내려도 다시 재생하지 않음.
- 페이지를 새로 열면 초기화.
- `prefers-reduced-motion: reduce`이면 모션 없이 찍힌 상태로 표시.
- 접근성: 각 이미지 `alt`에 문구를 넣는다(위 표). 장 제목 텍스트는 그대로 유지되므로 도장을 장식으로 볼 경우 `alt=""`도 가능 — 기획 판단.

## Figma와 다른 점 (의도)

- Figma 프레임 안에서는 0.3초부터 0.5초 간격으로 순서대로 찍히도록 타임라인을 만들었다(스크롤 재생을 Figma에서 설정할 수 없어서). 실제 페이지는 위 재생 규칙대로 스크롤에 맞춰 장마다 재생한다.

## 디자인 수정 시

1. Figma에서 `Stamp_NN` 레이어(`Stamp / Text`·`Stamp / Border`, 질감 효과 Texture·Noise) 수정
2. 해당 도장을 **회전 0으로 복제**해 PNG 3x로 내보내기(Figma 앱의 Export에서 투명 PNG로 내보내면 됨) → 2x는 3x를 2/3로 축소
3. 폭이 바뀌면 이 문서 표와 `stamps.css`의 `--w`(이미지 3x 폭 ÷ 3), `--frame-w`(Figma 프레임 폭) 갱신. 이미지 여백이 사방 2px가 아니면 `--w`만 이미지 폭에 맞추면 됨(중심 배치라 위치는 그대로)
